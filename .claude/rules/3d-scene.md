# 3D 씬 규칙

## 구조

- `<Canvas>`는 `src/components/world/World.tsx` 한 곳. 페이지에서는 `next/dynamic(..., { ssr: false })`로 불러온다.
- 마을 배치(NPC 위치, 집, 나무, 충돌체)는 `src/lib/village.ts`의 **순수 함수**가 `people.json`으로부터 계산한다. 시드 고정 난수를 써서 새로고침해도 같은 자리에 같은 사람이 서 있어야 한다. `Math.random()` 금지.
- 외부 3D 모델 파일(GLB)은 쓰지 않는다. 캐릭터·건물·나무는 전부 기본 도형으로 만든 로우폴리다.

## 성능 (NPC가 150명 안팎이다)

- NPC, 나무, 집처럼 반복되는 것은 반드시 `InstancedMesh`. NPC 한 명당 mesh를 여러 개 만드는 방식 금지.
- 이름표는 DOM(`<Html>`)이 아니라 캔버스 텍스처 스프라이트. 멀리 있는 이름표는 숨긴다.
- `useFrame` 안에서 `setState` 금지, 객체 새로 만들기(`new Vector3()`) 금지 — 모듈 스코프 임시 객체를 재사용한다.
- 매 프레임 바뀌는 값(플레이어 위치 등)은 ref나 zustand의 `getState()`로 읽는다. React 상태로 구독하는 것은 "가까운 NPC가 누구인지", "열린 문서가 무엇인지"처럼 드물게 바뀌는 값뿐이다.
- 그림자는 방향광 하나만. `dpr`은 `[1, 2]`로 제한.

## 조작

- 이동: WASD/방향키 (카메라 기준). 모바일: 화면 조이스틱.
- 대화: NPC 반경 안에서 `E`/`Space`/`Enter` 또는 화면 버튼. 문서가 열려 있는 동안은 이동 입력을 무시한다.
- 카메라: 드래그로 회전, 휠/핀치로 줌. 플레이어를 따라간다.
- 충돌은 물리엔진 없이 원(플레이어) 대 원/사각형(장애물, NPC)으로 직접 처리한다.

## 접근성

- WebGL이 없거나 3D가 부담스러운 사용자를 위해 **주민 명부**(이름 목록 → 글 바로 열기)를 항상 제공한다. 3D는 탐색 방식이지 유일한 진입로가 아니다.
