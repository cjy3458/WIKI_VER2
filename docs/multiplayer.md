# 메타버스(함께 접속) 설계

## 목표

위키 마을에 **지금 접속해 있는 다른 사람들이 보이고, 만나서 채팅할 수 있게** 한다.
전제는 그대로다: 우리 서버 없음, Next.js 하나, 계정 없음.

## 범위

| 한다 | 안 한다 |
|---|---|
| 닉네임·옷 색 정하기 — 자동으로 붙고, 들어온 뒤 접속자 목록에서 바꾼다 (브라우저에만 저장) | 로그인, 계정, 프로필 저장 |
| 다른 접속자의 아바타·이름표가 실시간으로 보임 | 음성·영상 통화 |
| 채팅: 말풍선(머리 위) + 채팅 기록(화면) + 이모지 인사 | 채팅 기록 저장 (새로 들어온 사람은 이전 대화를 못 본다) |
| 접속자 수·목록, 미니맵에 다른 사람 표시 | 방 나누기, 귓속말, 친구 |
| 보기 싫은 사람 숨기기(내 화면에서만, 이번 접속 동안) | 신고·관리자·금칙어 (관리 주체가 없다) |

위키 글(주민 NPC)은 지금처럼 읽기 전용이다. 접속자는 글을 쓰거나 고칠 수 없다.

## 방식: 서버 없는 P2P

```
브라우저 A ──(공개 Nostr 릴레이: "나 이 방에 있어" 신호만)── 브라우저 B
     └───────────── WebRTC 데이터 채널로 직접 연결 ─────────────┘
                    위치 · 닉네임 · 채팅이 여기로 오간다
```

- 라이브러리: `trystero` (기본 Nostr 전략). 서로를 찾는 신호만 공개 릴레이를 거치고, 실제 데이터는 브라우저끼리 직접 암호화 채널로 주고받는다.
- 키·계정·요금이 없다. 정적 호스팅에서도 그대로 동작한다.
- 통신 코드는 `src/lib/net.ts` 한 파일에 가둔다. 나중에 Supabase Realtime 등으로 바꾸려면 이 파일만 갈아 끼운다(`trystero`가 supabase 전략도 제공).

### 알고 가는 한계

- **회사·학교망 등 일부 네트워크에서는 연결이 안 될 수 있다**(TURN 서버가 없다). 그 경우 혼자 접속한 것처럼 보일 뿐 나머지는 정상 동작한다.
- 전원이 서로 직접 연결하는 구조라 **동시 접속 20~30명 정도**가 현실적인 상한이다. 아카이브 사이트 규모에는 충분하다.
- 공개 릴레이 상태에 따라 서로 보이기까지 몇 초~십몇 초 걸릴 수 있다.
- 연결된 상대에게는 WebRTC 특성상 내 IP가 노출될 수 있다. 접속자 목록 아래에 "브라우저끼리 직접 연결된다"는 안내를 둔다.

## 주고받는 데이터

| 액션 | 내용 | 주기 |
|---|---|---|
| `hello` | `{ name, color }` | 상대가 들어올 때, 내 프로필이 바뀔 때 |
| `pos` | `[x, z, rot, speed]` | 움직일 때 초당 10회, 서 있을 때 초당 1회 |
| `chat` | `{ t: 글자 }` | 보낼 때 |

받은 값은 전부 검증한다: 타입, 길이(닉네임 12자, 채팅 100자), 좌표 범위, 상대별 채팅 빈도(0.5초에 1개). 채팅은 React 텍스트로만 그린다(HTML로 해석하지 않는다).

## 화면

- **입장**: 묻지 않는다. 닉네임은 `아기사자###`로 자동. 왼쪽 위 접속자 목록에서 닉네임·옷 색 변경
- **마을**: 다른 접속자는 주민과 같은 사자 모양이지만 이름표가 어두운 색이라 구분된다. 주민(NPC)은 밝은 이름표 + 파트 색 점.
- **채팅**: `Enter`로 입력창, 다시 `Enter`로 전송. 머리 위 말풍선 6초, 화면 왼쪽 아래에 최근 대화.
- **HUD**: "지금 N명 접속 중" + 접속자 목록(숨기기 버튼)

## 상태 구조

- `useNet`(zustand): 연결 상태, 내 프로필, 접속자 목록, 채팅 기록, 말풍선, 숨긴 사람 — 드물게 바뀌는 값
- `remotes`(Map, plain object): 다른 접속자의 위치 — 프레임 루프에서 직접 읽고 보간한다

## 구현 순서

1. `src/lib/net.ts` — 연결, 송수신, 검증
2. `src/components/world/Visitors.tsx` — 다른 접속자 아바타, 이름표, 말풍선
3. `src/components/ui/ChatBox.tsx` + HUD/입장 화면 수정
4. 두 개의 브라우저로 서로 보이는지·채팅이 오가는지 확인
