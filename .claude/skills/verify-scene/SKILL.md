# 3D 씬 동작 확인

빌드 성공은 씬이 보인다는 뜻이 아니다. 브라우저에서 확인한다.

## 절차

1. 개발 서버를 백그라운드로 띄운다: `npm run dev` → `http://localhost:3000`
2. Playwright MCP(`.mcp.json`)로 페이지를 연다. MCP가 없으면 사용자에게 직접 확인을 부탁하고, 확인하지 못했다고 명시한다.
3. 체크리스트
   - [ ] 첫 화면이 구버전 위키와 같다(로고 바, 제목, 창 그림, CLICK! 배지). 입력창이 없다
   - [ ] 창 그림을 누르면 창 속 하늘로 확대된 뒤 모달 없이 바로 광장이 보인다 (스크린샷으로 지형·NPC·이름표 확인)
   - [ ] 콘솔에 에러/경고(특히 hydration, WebGL context lost)가 없다
   - [ ] `↑` 방향키를 1초 누르면 캐릭터 위치가 바뀐다 (전/후 스크린샷 비교)
   - [ ] NPC 근처에서 "말 걸기" 안내가 뜨고, `Space`를 누르면 대화창 → 글이 열린다
   - [ ] 글 안의 이미지가 `/wiki-images/`에서 로드된다 (404 없음). 본문에 `<img` 글자가 그대로 보이는 곳이 없다 — 원문 `<img` 개수와 화면의 `.wiki img` 개수가 같아야 한다
   - [ ] 이미지를 누르면 크게 보이고, `Esc` 한 번에 확대만 닫히고 글은 남는다
   - [ ] 글 안의 다른 사람 링크를 누르면 그 사람 글로 넘어간다
   - [ ] `Esc`로 닫으면 다시 움직일 수 있다
   - [ ] 섬이 파란 모눈 허공에 떠 보인다(하늘이 단색이 아니라 모눈). 휠로 멀리 당기면 네모난 섬 전체와 타워·포털·모닥불·연못이 보인다
   - [ ] 입장 지점에서 `↑`만 누르고 있으면 길을 따라 WIKI 타워 터미널에 닿고, `Space`로 주민 찾기 창이 열린다
   - [ ] 랜덤 포털 앞에서 `Space` → 아무 주민 앞으로 이동한다
   - [ ] 주민 찾기(Tab)에서 이름 입력 후 Enter → 그 사람 바로 앞으로 이동하고 "말 걸기"가 뜬다
   - [ ] 주민 찾기에서 "글 보기"로 글을 바로 열 수 있다
   - [ ] **함께 접속**: 브라우저 두 개(서로 다른 프로세스 또는 탭)로 들어가면 30초 안에 양쪽 모두 "지금 2명 접속 중"이 되고, 한쪽이 움직이면 다른 쪽 화면에서도 움직이며, 채팅이 양방향으로 오간다. 한쪽을 닫으면 1명으로 돌아온다
   - [ ] 채팅에 `<b>굵게</b>` 같은 HTML을 보내도 글자 그대로 보인다
   - [ ] 뷰포트 390×844(모바일)에서 조이스틱과 버튼이 보이고 겹치지 않는다
4. 실패 항목은 원인을 찾아 고친 뒤 해당 항목만 다시 확인한다.
5. 개발 서버를 종료한다.
