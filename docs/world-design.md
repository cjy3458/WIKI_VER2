# 픽셀 세계 공간 기획

## 컨셉: "창 속의 섬" — LIKELION.EXE

구버전 위키 첫 화면에는 **파란 모눈 바탕 위에 브라우저 창이 하나 떠 있고, 그 창 안에 픽셀 사자가 사는 작은 세계**가 그려져 있었다.
이번 공간은 그 그림 속으로 들어간다. 접속자는 컴퓨터 화면 안, 파란 모눈 공간에 떠 있는 **네모난 픽셀 섬**에 내려선다.

| 구버전 위키의 요소 | 3D 공간에서 |
|---|---|
| 파란 모눈 배경 `#4C4DF5` | 섬 바깥의 허공. 하늘 대신 모눈이 보인다 |
| 검은 테두리 + 그림자의 브라우저 창 | 모든 UI 창(입장·글·찾기)과 "랜덤 포털" 건축물 |
| 잔디 블록 / 흙벽돌 단면 / 물 | 섬 윗면 / 섬 옆면과 길 / 연못 |
| 픽셀 구름, 얼굴 달린 해 | 블록 구름, 하늘의 픽셀 해 |
| 픽셀 사자, 하트 | 주민·접속자 아바타, 광장 위에 떠 있는 하트 |
| 둥근모 폰트 | 이름표·표지판·제목 |

원칙: **둥근 것이 없다.** 섬도 광장도 길도 나무도 네모다. 길은 격자 방향으로만 뻗는다.

## 배치

```
                      N
        ┌──────────────────────────────┐
        │        [ WIKI 타워 ]          │   거대한 CRT 모니터. 화면에 CAU LIKELION WIKI
        │          ▒ 터미널 ▒           │   앞의 키보드 = 주민 검색
        │             ║                │
        │             ║ 길              │
        │ (모닥불)     ║        (랜덤    │
        │  라운지 ════[광장]════  포털)   │   광장: 황금 사자상 + 떠 있는 하트. 입장 지점
        │             ║                │
        │             ║        ~연못~   │
        │             ║                │
        └──────────────────────────────┘
          섬 144 × 144, 옆면은 흙벽돌, 바깥은 파란 모눈
```

| 건축물 | 위치 | 역할 | 인터랙션 |
|---|---|---|---|
| **START 광장** | 중앙 | 입장 지점, 만남의 장소. 황금 사자상과 하트 3개 | — |
| **WIKI 타워** | 북쪽 끝 | 어디서나 보이는 랜드마크. 화면에 위키 로고 | 앞 터미널에서 `Space` → 주민 찾기 창 |
| **랜덤 포털** | 동쪽 | 브라우저 창 모양의 문. 구버전의 "랜덤 문서" 기능 | 앞에서 `Space` → 아무 주민 앞으로 이동 |
| **모닥불 라운지** | 서쪽 | 접속자들이 모여 떠드는 곳. 불과 통나무 의자 | `Enter` 채팅 (어디서나 되지만 모이는 장소를 준다) |
| **연못** | 남동쪽 | 구버전 그림의 물 블록. 쉬어 가는 풍경 | — (들어갈 수 없다) |
| 집·나무 | 섬 전체 | 블록 집 12채, 블록 나무 64그루. 사자를 가리지 않게 듬성듬성 | — |
| 픽셀 해 | 북동쪽 하늘 | 구버전 창 그림의 해를 블록으로. 구름처럼 하늘에 떠 있다 | — |

주민 58명은 기수 구분 없이 섬 전체에 흩어져 있다(광장·건축물·길 위는 비운다).

## 인터랙션 시나리오

1. **입장** — 첫 화면은 구버전 위키의 첫 화면 그대로다. 브라우저 창 그림(옆에 `CLICK!`)을 누르면 화면이 그 창 속 하늘로 빨려 들어가고, 하늘색이 걷히면서 카메라가 섬 위 높은 곳에서 광장의 내 캐릭터 뒤로 내려온다. 아무것도 묻지 않는다. 닉네임은 자동으로 붙고 나중에 바꿀 수 있다.
2. **산책하다 만나기** — 방향키로 걷다 이름표 달린 사자 옆에 서면 발밑에 고리가 생긴다. `Space` → 그 사람의 위키 글.
3. **찾아서 만나기** — 타워 앞 터미널에서 `Space`(또는 어디서나 `Tab`) → 이름 입력 → `Enter` → 그 사람 앞으로 이동.
4. **우연히 만나기** — 랜덤 포털에서 `Space` → 누구일지 모르는 주민 앞에 떨어진다. 계속 타고 다니며 읽을 수 있다.
5. **사람 만나기** — 어두운 이름표는 지금 접속한 다른 사람이다. `Enter`로 말을 걸면 머리 위에 말풍선이 뜬다. 모닥불에 모여 앉아 떠든다.
6. **둘러보기** — 드래그로 시점을 돌리고 휠로 멀리 당기면 모눈 허공에 떠 있는 섬 전체가 보인다.

## 구현 메모

- 하늘을 그리지 않는다. 캔버스를 투명하게 하고 뒤의 CSS 모눈 배경이 비치게 한다. 안개도 없다.
- 픽셀 질감은 작은 캔버스(16×16)에 그린 텍스처를 `NearestFilter`로 반복한다. 이미지 파일을 쓰지 않는다.
- 이름표가 읽혀야 하므로 화면 전체를 저해상도로 뭉개는 방식은 쓰지 않는다. 픽셀 느낌은 블록 형태·질감·폰트·UI로 낸다.
- 건축물은 `src/lib/village.ts`의 `landmarks`, `spots`에 좌표로 정의하고 주민·집·나무 배치가 이를 피한다.
- 폰트: 둥근모(NeoDunggeunmo Pro, OFL)를 저장소에 넣어 직접 서빙한다.
