# 멋사 중앙대 위키 마을

멋쟁이사자처럼 중앙대학교 위키(`wiki.cau-likelion.org`)의 읽기 전용 아카이브입니다.
서버는 내려갔지만, 우리가 서로에 대해 써 둔 글은 여기 남겨 둡니다.

이름을 검색하는 대신 **3D 마을을 걸어 다니다가 이름표가 붙은 사자를 만나 말을 걸면** 그 사람의 위키 글이 열립니다.

## 들어가는 법

첫 화면은 예전 위키의 첫 화면 그대로입니다. **브라우저 창 그림(`CLICK!`)을 누르면** 그 창 속으로 빨려 들어가 바로 마을에 서 있게 됩니다. 닉네임은 자동으로 정해지고, 들어간 뒤 왼쪽 위 "닉네임 바꾸기"에서 바꿀 수 있습니다.

## 공간: 창 속의 픽셀 섬

예전 위키 첫 화면에는 파란 모눈 바탕 위에 브라우저 창이 하나 떠 있고, 그 안에 픽셀 사자가 사는 작은 세계가 그려져 있었습니다. 이 마을은 그 그림 속입니다.

| 장소 | 위치 | 할 수 있는 것 |
|---|---|---|
| START 광장 | 중앙 | 입장 지점. 황금 사자상과 하트 |
| WIKI 타워 | 북쪽 | 거대한 모니터. 앞 터미널에서 `Space` → 주민 찾기 |
| 랜덤 포털 | 동쪽 | 브라우저 창 모양의 문. `Space` → 아무 주민 앞으로 (예전의 "랜덤 문서") |
| 모닥불 라운지 | 서쪽 | 접속한 사람들이 모여 떠드는 곳 |
| 연못 | 남동쪽 | 예전 그림의 그 물 블록 |

## 들어 있는 것

- 원본 위키의 **11기·12기 사람 문서 58개** (11기 27명, 12기 31명. 프로젝트·소모임·기수 문서와 다른 기수는 제외)
- 본문에 쓰인 이미지 86장 (원본 S3에서 내려받아 `public/wiki-images/`에 보관)
- 글은 원문 그대로입니다. 바뀐 것은 링크와 이미지 경로뿐입니다. 글 속 이미지는 누르면 크게 볼 수 있습니다.

편집, 로그인, 수정 이력, 역링크 기능은 없습니다.

## 함께 접속

같은 시간에 들어와 있는 사람들이 마을에서 서로 보이고 채팅할 수 있습니다.

- 닉네임과 옷 색은 들어간 뒤 왼쪽 위 접속자 목록에서 바꿉니다(내 브라우저에만 저장).
- 다른 접속자는 **어두운 이름표**, 위키 주민은 밝은 이름표로 구분됩니다.
- `Enter`로 채팅을 치면 머리 위 말풍선과 화면 왼쪽 아래 기록에 나타납니다. **채팅은 어디에도 저장되지 않습니다.**
- 서버 없이 브라우저끼리 직접 연결하는 방식(WebRTC P2P)이라, 회사·학교망 등 일부 네트워크에서는 다른 사람이 안 보일 수 있습니다. 그래도 글 읽기는 정상 동작합니다.
- 관리자가 없는 공간입니다. 보기 싫은 사람은 왼쪽 위 접속자 목록에서 "숨기기"를 누르세요.

## 조작

| | 키보드·마우스 | 터치 |
|---|---|---|
| 이동 | 방향키, `Shift` 달리기 | 왼쪽 아래 조이스틱 |
| 말 걸기 / 장치 쓰기 | 주민·터미널·포털 가까이에서 `Space` | 화면의 "말 걸기" 버튼 |
| 둘러보기 | 드래그로 회전, 휠로 줌 | 한 손가락으로 밀기, 두 손가락으로 줌 |
| 채팅 | `Enter` → 입력 → `Enter` | 왼쪽 아래 입력창 |
| 주민 찾기 | `Tab` → 이름 입력 후 `Enter` | 오른쪽 위 버튼 |

11기와 12기는 구역 구분 없이 한 섬에 섞여 흩어져 있고, 옷 색은 파트를 뜻합니다. 특정 사람을 만나고 싶으면 주민 찾기에서 이름을 입력하고 Enter를 누르세요. 그 사람 바로 앞으로 이동합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 프로덕션 빌드
```

Node 20 이상. 서버나 환경 변수는 필요 없습니다.

## 구조

```
scripts/build-data.mjs     원본 DB(CSV) → JSON 변환기
src/data/generated/        변환된 글 데이터 (직접 수정하지 않음)
public/wiki-images/        본문 이미지
src/lib/village.ts         누가 어디에 서 있는지 계산 (시드 고정, 항상 같은 자리)
src/components/world/      3D 씬 (React Three Fiber)
src/components/ui/         글 뷰어, 주민 찾기, HUD
```

기술 스택: Next.js 16 · React 19 · three.js / React Three Fiber · zustand · Tailwind CSS v4 · trystero(P2P)

## 데이터 다시 만들기

원본 DB 덤프가 있는 사람만 할 수 있습니다. **원본 DB는 이 저장소에 올리지 않습니다**(계정 정보가 들어 있습니다).

```bash
npm run build:data -- "<원본 DB가 들어 있는 폴더>"
```

특정 사람의 글을 내리려면 `scripts/build-data.mjs`의 `EXCLUDE_TITLES`에 이름을 추가하고 다시 생성하세요.
본인 글을 내리고 싶다면 저장소 이슈로 알려 주세요.
