# 검증 규칙

테스트 프레임워크는 두지 않는다(아카이브 규모에 비해 과하다). 대신 변경 후 아래를 실제로 돌린다.

1. `npm run lint` — 경고 0
2. `npm run build` — 타입 에러 0, 빌드 성공
3. 데이터를 건드렸다면 `npm run build:data` 출력의 요약(사람 수, 이미지 수, 경고)을 확인하고, 이전과 달라졌으면 이유를 설명할 수 있어야 한다.
4. 3D/UI를 건드렸다면 `npm run dev`로 띄워 직접 본다: 캐릭터가 움직이는지, NPC에게 말을 걸면 글이 열리는지, 콘솔 에러가 없는지. 절차는 `verify-scene` 스킬.

"빌드가 되니까 된다"로 끝내지 않는다. 화면에서 확인하지 못했으면 못 했다고 말한다.
