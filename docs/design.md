# 설계

## 목표

서버 없이 Next.js 하나로, 11기·12기 사람들의 위키 글을 "마을에서 만나 말을 거는" 방식으로 읽게 한다.

## 데이터 흐름

```
원본 DB (Django CSV 덤프, 저장소 밖)
   │  scripts/build-data.mjs  ← 사람이 직접 실행, 빌드 파이프라인에는 없음
   ▼
src/data/generated/people.json + public/wiki-images/*.webp   (커밋됨)
   │  import
   ▼
src/lib/people.ts ──▶ src/lib/village.ts (배치 계산) ──▶ 3D 씬 / UI
```

위키 글을 런타임에 네트워크로 받아 오지는 않는다(접속자 간 P2P 통신은 별개). 페이지는 전부 정적으로 프리렌더된다.

### 누가 들어가는가

| 단계 | 기준 | 결과 |
|---|---|---|
| 전체 문서 | `documents_currdoc` | 222 |
| 11기 또는 12기 태그 | 최신 버전(`history_doc_id`)에 붙은 `documents_generation` 태그 | 119 |
| 그중 사람 | 기수 문서(`N기`)의 인물 표에 링크된 제목 + `EXTRA_PEOPLE` | 74 |
| 그중 11기·12기 소속 | 인물 표에 11기 또는 12기 아기사자로 올라 있음 | **58** |

태그는 문서가 아니라 **버전(수정 이력)** 에 붙는다(`documents_generation.title_id` → `historydoc.id`). 태그 값은 그 사람이 활동한 기수 전부라서, 10기 아기사자였지만 11기 운영진을 한 사람은 `10기/11기`로 포함된다. 그래서 태그만으로는 9·10기 사람이 16명 섞이므로, 인물 표의 소속 기수로 한 번 더 거른다.

## 마을

- 기수별 구역은 없다. 11기·12기 태그를 둘 다 가진 사람이 14명이라 나누는 의미가 없다. 주민 58명은 광장 둘레 반경 13~60 안에 서로 8 이상 떨어져 흩어져 있다. 옷 색 = 파트.
- 주민 찾기에서 이름을 입력하고 Enter를 누르면 그 사람 바로 앞 빈자리로 순간이동하고, 카메라가 등 뒤로 돌아 마주 보게 된다.
- 배치는 시드 고정 난수로 계산하므로 언제 접속해도 같은 사람이 같은 자리에 있다.

## 렌더링

| 대상 | 방식 | 드로우콜 |
|---|---|---|
| 주민 58명 | `InstancedMesh` 2개 (몸 / 옷) | 2 |
| 이름표 | 캔버스 텍스처 스프라이트, 44 유닛 밖은 숨김 | 보이는 수만큼 |
| 집·나무·구름 | `InstancedMesh` | 4 |
| 플레이어 | 팔다리가 따로 움직이는 mesh 7개 | 7 |

- 외부 모델 파일 없음. 사자는 구버전 픽셀 마스코트를 상자로 옮긴 것.
- 물리엔진 없음. 충돌은 전부 원 대 원.
- 매 프레임 바뀌는 값(위치, 입력, 카메라)은 React 상태가 아니라 `src/lib/store.ts`의 plain object. React가 구독하는 것은 "가까운 주민", "열린 글", "주민 찾기 열림"뿐이다.

## 본문 렌더링

`react-markdown` → `remark-gfm`, `remark-breaks`(원본 뷰어가 줄바꿈을 그대로 보여 줬다) → `rehype-raw` → 이미지 폭 보존 → `rehype-sanitize`.

- 원문의 `<img style="width: 30%">`는 sanitize가 style을 지우므로, 그 전에 숫자만 `data-width`로 옮겨 살린다.
- 들여쓰기·따옴표 오타로 `<img>`가 글자로 보이는 원문은 그리기 직전에만 보정한다(`repairMarkup`). 저장된 본문은 그대로다.
- 이미지는 버튼으로 감싸 누르면 `Lightbox`로 화면 가득 보여 준다. `Esc`는 확대 → 글 → 주민 찾기 순으로 하나씩 닫는다.
- `#wiki/<이름>` 링크는 아카이브에 그 사람이 있으면 그 글로 넘어가는 버튼, 없으면 점선 밑줄 텍스트.

## 함께 접속

다른 접속자와의 실시간 연결·채팅은 별도 문서 `docs/multiplayer.md` 참고. 위키 데이터 흐름과는 완전히 분리돼 있다.

## 3D를 못 쓰는 경우

WebGL이 없으면 안내 문구와 함께 주민 찾기만으로 모든 글을 읽을 수 있다.
